# e-plantShopping

e-plantShopping is a React shopping cart application created for Paradise Nursery, an online houseplant store.

The application allows users to browse plants by category, view plant details, add products to a shopping cart, update quantities, remove items, and view the total cart cost.

## Main Features

- Landing page for Paradise Nursery
- Product listing grouped by plant categories
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease product quantities
- Remove products from the cart
- Dynamic total price calculation
- Continue Shopping and Checkout buttons

## Technologies

- React
- JavaScript
- CSS
- Redux Toolkit
